# 多工具交接核对

AGENTS.md 是开工、验证和发布规则的唯一来源；已读取且未变化时不重读。

1. 检查工作区及 TASK_PROGRESS 中未完成的相关条目。真实重叠占用需协调；已完成/待开始不是锁。
2. 仅检索相关决策及最近改动，证据不足再扩展。不加载整个 wiki，不将归档列为必读。
3. 交接保留目标、文件、分支/提交、未提交修改、验证及阻碍；开始/结束各登记一次，不逐工具调用更新。
4. 已完成的检查复用，代码或环境变化才重验；超过 3 个文件不额外要求确认。
5. 日常不自动升版本或发布；仅用户明确要求发布时按 AGENTS.md 第 7 节执行，并核实真实 APK 附件。
